# RPG Weaver: a Browser-Based RPG Maker Web Alternative

I've been using RPG Maker for years, so I know its strengths inside out: the sheer speed of turning an idea into a playable 2D world is genuinely unmatched. But if you've spent enough time with it, you know its frustrating quirks and limitations all too well.

That's why I started building **RPG Weaver**: a free, web-based 2D engine and map editor that runs right in your browser. It keeps the straightforward logic and quick workflow that makes 2D dev fun, minus the clunky legacy baggage or desktop installs.

<Callout type="warning">
  RPG Weaver is under active development. You can already build full playable games with it, and any feedback you have helps shape what gets built next!
</Callout>

---

## Why an RPG Maker Web Alternative?

If you're looking for a browser-based **RPG Maker Web** editor or a modern **RPG Maker alternative**, RPG Weaver gives you the classic tile-based workflow you already know, paired with modern quality-of-life improvements:

- **100% Web-Native & Free**: Build, tweak, and playtest your game directly in the browser—no installer needed. You can also install it as a PWA if you prefer a dedicated window.
- **Familiar RPG Maker Logic**: Autotiling, global switches & variables, self-switches (and self-variables!), conditional branches, loops, timers, input checks, audio, pictures, text dialogs with typewriter effect, movement routes, and more.
- **Modern Workflow Perks**: Custom inputs, unlimited map layers, smooth sub-pixel movement, custom viewport resolutions, and snappy search/filtering across events, switches, variables, and assets.

## Key Features

### Event Templates & Reusable Logic

Save time by defining reusable **Event Templates**. Instead of copying and pasting common event setups (like treasure chests, doors, NPCs, or standard interaction triggers) across every map, create a template once and drop instances wherever you need them, even at runtime with the "Spawn Event" command.

<Video src={event_templates} class="my-0" />

### Multi-Area Events & Region Hitboxes

Events aren't locked to a single 1×1 tile. You can draw custom rectangular hitboxes or set dimensions directly in the event editor—perfect for wide doors, zone triggers, cutscene areas, and large interactive objects without needing dummy clone events.

<Video src={events} class="my-0" />

### Flexible Tilesets & Collision Editing

- **Multiple Tile Size Standards**: Support for **16×16**, **32×32**, **48×48**, and **64×64** tilesets, so retro and modern pixel art both look right at home.
- **Tileset Configuration**: Configure tiling modes, customize frame counts, and adjust playback speed for animated tiles.
- **Passage & Collision**:
  - Global passage flags.
  - Directional **4-way passage**.
  - **Terrain Tags** for region and surface logic.

<Video src={tilesets} class="my-0" />

### Unlimited Layering Stack

- **Unlimited Map Layers**: No arbitrary layer caps. Add as many layers as your map actually calls for.
- **Custom Layer Ordering**: Drag and drop layers to adjust render order and dial in visual depth.

<Video src={layers} class="my-0" />

### Integrated Sub-Pixel Movement

- **Grid & Sub-Pixel Movement**: Stick with classic grid-stepping or turn on smooth, continuous **sub-pixel movement**.

### Flexible State & Variable Scope

- **Self Variables**: On top of global switches, global variables, and self-switches, RPG Weaver includes per-event self-variables—ideal for standalone counters, multi-state puzzles, and modular logic.
- **Persistent Event Coordinates**: Let events permanently remember their updated map positions across game saves.

### Event Commands & Camera Controls

- **Dynamic Camera Controls**: Pan or lock the camera onto the player or any map event on the fly.
- **Smarter Movement Routes**: Have events follow or run away from any target event.
- **Map Transfers**: Teleport the player or send events between different maps.

### Custom Game Viewport & Resolution

- **Flexible Viewport Resolution**: Pick whatever width, height, or aspect ratio fits your game best.

### Customizable Controls & Keybindings

- **Input Rebinding**: Remap keyboard keys for any core action.
- **Mouse & Touch Support**: Optional toggle for point-and-click movement and UI navigation.

<Video src={inputs} class="my-0" />

### Asset & Resource Manager

- **Organized Project Assets**: Import, preview, and categorize your audio, sprites, and tilesets in one place.
- **Fast Search & Filters**: Quickly find any sound effect, switch, variable, or graphic asset.
- **Built-in Audio Player**: Preview BGMs and SFX right in the editor with playback scrubbing.

## Roadmap & What's Next

RPG Weaver is still growing. Here's a look at what's currently in the works:

- **Battle System**: Turn-based and real-time combat options.
- **Party Management**: Party setup, member swapping, and reserve members.
- **Plugin System**: Scripting and extensibility to tweak engine behavior.
- **Google Drive Backups**: Sync your project files straight to Google Drive so nothing gets lost.
- **Shareable Play Links**: One-click playable web links to share your game with testers and friends instantly.
- **RPG Maker Project Import**: Import existing RPG Maker projects straight in and keep building without starting from scratch.
